## 📖 What is feather?

feather is a free and open-source application that makes your digital files smaller and easier to share. If you've ever tried to email a large video, upload a heavy photo to a website, or send a bulky PDF through chat, you know how frustrating file size limits can be.

With feather, you can compress (shrink) your files quickly and easily. The best part? Everything runs **directly on your computer** — your files never leave your device, keeping them completely secure and private.

## 🎯 How to Use feather (Simple Guide)

### Compress a Single File
1. **Launch feather** from your Applications folder
2. **Drag and drop** any video, image, GIF, or PDF file into the feather window
3. **Choose a quality setting** — higher quality means larger files; lower quality means smaller files
4. Click **"Compress"** and wait a few seconds
5. Your compressed file will appear in the same location as the original, with "_compressed" added to the filename

### Compress a Folder Automatically
1. Open feather
2. Click **"Auto-Compress Folder"** in the sidebar
3. Select any folder on your computer
4. feather will automatically compress new media files added to that folder from now on

### Use the Finder Quick Action
1. **Locate a file** you want to compress in Finder
2. **Right-click** on the file (or Control-click)
3. Scroll down to **"Quick Actions"**
4. Select **"Compress with feather"**
5. Done! Your file is instantly compressed

## ❓ Frequently Asked Questions

### Is feather really free?
Yes! feather is completely free and open-source. No subscriptions, no hidden fees, no premium tiers.

### Will my files be uploaded anywhere?
No. All compression happens locally on your device. Your files never leave your computer.

### What file formats are supported?
feather supports a wide range:
- **Videos:** MP4, MOV, AVI, MKV, and more
- **Images:** JPG, PNG, GIF, BMP, TIFF, and more

### Will I lose quality?
feather uses smart compression algorithms to minimize visible quality loss. You can choose how much quality to sacrifice for file size. For most uses, you won't notice any difference.

### Is feather available for Windows or Linux?
Currently, feather is designed for macOS only. Windows and Linux versions are planned for future releases.

## 🛠️ Technical Details (For Curious Users)

feather is built with modern technology:

- **Advanced Formats:** Supports AVIF, WebP, and HEVC encoding for maximum compression efficiency
